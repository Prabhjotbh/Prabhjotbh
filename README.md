- Designed state / action spaces, reward shaping, and multi-difficulty scenarios for agent evaluation
- Stack: Python · FastAPI · Pydantic · Docker

### [Sahayak](https://github.com/Prabhjotbh/Sahayak) · [SahayakAI](https://github.com/Prabhjotbh/SahayakAI)

- End-to-end operator dashboard: live calls, map tracking, dispatch, and chat
- AI-assisted prioritization, emotion cues, and real-time guidance for responders
- Stack: TypeScript · React · Vite · Tailwind · shadcn/ui · React Query
